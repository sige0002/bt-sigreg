# ABCの独立数学監査：成立する命題と研究目的との隔たり

2026-09-07。数学者役の独立エージェントによる監査であり、実在の数学者・外部査読者による査読ではない。
対象はルートREADME、mylewm/README、研究候補レポート、[A #8](https://github.com/sige0002/task-centered-sigreg-lewm/issues/8)、[B #12](https://github.com/sige0002/task-centered-sigreg-lewm/issues/12)、[C #13](https://github.com/sige0002/task-centered-sigreg-lewm/issues/13)の現在の本文。
旧B #9・旧C #10とは区別する。検索・先行研究の書誌確認は別担当であり、本稿は独立の数学検討を記す。

## 結論

ABCはいずれも定義可能で、issueの主要な勾配式は正しい。しかし「正しい式」から「後続タスクに必要な情報を保持する」「少量データで未見の操作を予測する」「TCより高精度になる」は導けない。

| 案 | 条件付きでできること | 現在の決定的な不足 | 数学的な判断 |
|---|---|---|---|
| A | 窓平均と時間残差への正則化を分離する | 分散がどの意味情報を担うか無指定。静止窓の残差Gaussian化が不適切 | 研究中心に合うが、原案を十分な情報保持機構と呼べない |
| A+ | 非零の平均共分散のスペクトル集中を罰する | 背景だけでも充足。正の罰則でも低rankからの脱出保証なし | Aの一つの反例への対処であり、A全体の解決ではない |
| B | 与えた候補集合に対する実測未来の識別を促す | 偽負例・背景識別。識別に不要な情報は残す必要がない | 意味情報を残す圧力はAより明示的だが、候補設計に依存 |
| C | 予測器の保持・更新に帰納バイアスを与える | 入力にない情報を救えず、自由な候補予測器との分解は非識別 | 予測時の忘却には合理的。Gaussian制約の直接解ではない |

研究目的に最も近い入口はA系だが、現段階でAを無条件の勝者にしない。Cは「観測表現では読めるが予測後に失う」という診断があるとき優先度が上がる。Bは候補識別が背景では解けないことを確認してから採用する。

## 1. 全案に共通する必要条件

### 1.1 観測・経験の識別可能性

同じモデル入力履歴に対して、観測できない物理状態によって次状態が異なるなら、決定論的E/Fが両者を同時に正確予測することはできない。MSEの母集団最適予測は条件付き平均であり、二峰性の結果では実在しない中間状態になる場合もある。

これは全配置の交差対応表を要求するという意味ではない。通常経験からの一般化は可能だが、未実行の行動領域では同じ訓練データに一致する複数の遷移則が存在し得る。ABCだけでその曖昧さを一般に除去する定理はない。

### 1.2 予測誤差と正則化だけでは「何を残すか」が不十分

潜在の教師Eも同時に学習する。ある物体情報をEから消せば、その物体の予測誤差も損失から消える場合がある。非崩壊正則化は他の変動を保存して満たせる。

必要なのは全画素保存ではなく、後続制御を区別する情報の保持である。「平均分散がある」「effective rankが高い」「未来識別精度が高い」だけでは、その十分性は証明されない。

### 1.3 Gaussian自体がマルチタスクを禁止するわけではない

単純な反例としてZが標準Gaussianでも、文脈K=1[Zの第1成分>0]は完全に読み出せる。Gaussian周辺分布と複数文脈の識別は両立する。

問題は有限容量・予測MSE・有限サンプルの下での幾何と分散配分である。全共分散は条件内共分散の期待値＋条件付き平均の共分散になる。単位共分散という共通予算が、必要な条件内・条件間変動を同時に簡潔に表現する際の制約になり得る。これは「Gaussianなら不可能」という定理ではない。

## 2. A：時間分解正則化

### 2.1 成立する恒等式と直交性

各クリップの平均m_bと残差r_bt=z_bt−m_bについて、時刻和が0なので、経験分散の分解v_Z=v_M+v_Rは厳密に成立する。分母はissueと同じcorrection=0とする。

平均罰則P(v_M)の勾配は

```math
\nabla_{z_{bt}}P=P'(v_M)\frac{2(m_b-\bar m)}{BDT}.
```

時刻tに依存しない。したがってzを自由な変数としてこの勾配だけで更新すれば、rは変わらない。残差だけの損失の勾配は逆に時刻和0となる。これは学習信号を分けるというAの合理性を支える。

ただし共有エンコーダの重みθを更新すると、表現更新は単純な−∇zではなく、局所線形化では−J_E J_E^T∇zになる。平均・残差枝がパラメータ空間で干渉しないという主張には拡張できない。

### 2.2 静的意味の同定ではない

時間平均は周波数上のDC成分であって、物理的な「非操作対象」を同定する演算ではない。移動物体の平均位置はmに入り、カメラノイズや照明のちらつきはrに入る。Tやframe skipで分解が変わる。

同じ観測の完全静止窓では、決定論的Eに対してr=0が必然である。その残差に非退化な単位Gaussianを要求しても同時充足できない。完全一致なら残差経路のエンコーダ勾配が相殺される場合もあり、わずかな観測差がある場合は意味のない差を増幅する可能性がある。「静止窓でも必ずノイズを増幅する」とまでは断定しない。

### 2.3 総分散だけの反例

クリップごとの背景1変数だけをmに保存し、その分散を調整すれば、重要な非操作物体情報がなくても帯域罰則は0にできる。平均側への圧力が無いTCとの差はあるが、帯域罰則だけでは保存対象を指定できない。

## 3. A+：participation ratio罰則

Xは中心化した平均表現、C=X^TX/B、a=tr C、s=||C||_F²+εとすると

```math
q=a^2/s,\qquad
\nabla_C q=\frac{2a}{s}I-\frac{2a^2}{s^2}C,
\qquad \nabla_M q=\frac2B X\nabla_C q.
```

H=[1−q/q0]_+²の勾配はこれに−2[1−q/q0]_+/q0を掛ける。独立の自動微分・有限差分検算で一致した。

ε=0で非零の半正定値Cなら1≤q≤rank(C)≤min(D,B−1)。ε>0では下限1は成立せず、qは尺度不変でもなくなる。Mをa倍すると分子・ε以外の分母はa^4倍なので、微小分散ではεの影響を明記する必要がある。直交回転不変性はε>0でも成立する。

### 3.1 低rankからの脱出は保証されない

rank 1のXが一つの座標方向だけを使う場合、ε=0ではq=1で、q0=4の罰則H=.5625が正でも、Xに対する勾配は0になる。ε>0なら使用中の方向に小さな尺度勾配は出得るが、未使用方向への直接勾配は依然0である。

完全崩壊点も共分散に対する微分が表現側で0になり、P＋Hは正でも勾配0となる。これはランダム初期化した実ネットワークが必ず崩壊するという主張ではない。対称点からの脱出保証がないこと、正の罰則と有効な更新方向を区別すべきことを示す。

また、独立な4つの背景変数だけでq=4を満たせる。タスク間平均差だけで満たす可能性もあり、タスク内の状態保持を別診断する必要がある。A+の追加はGaussian形状の問題への完全解ではなく、低rankの一部を罰する補助である。

## 4. B：系列内外の未来識別

### 4.1 主要な式は正しい

候補全集合C、正例集合P、二乗距離scoreについて

```math
\ell=\operatorname{LSE}_{C}(s)-\operatorname{LSE}_{P}(s),\qquad
\nabla_q\ell=\frac2{D\tau}\left(\sum_C\pi_c y_c-\sum_P\pi_p^+y_p\right).
```

正例が候補に含まれ、非空・maskの条件を満たせば負の対数尤度として定義できる。有限差分はqと教師keys双方で一致した。ただし候補を特定規則で選び、教師も学習するので、一般のInfoNCEの相互情報量評価や固定教師分類の保証を無条件に継承しない。

### 4.2 見逃しやすい反例

- 全q/yが同じなら、正例数P、候補数Kに対してloss=log(K/P)でも潜在勾配0となる。SIGRegを残す理由は合理的だが、組合せでの大域収束保証は別問題。
- 複数正例のlogsumexpは「正例集合のどれかへ確率を割り当てる」目的で、全正例への接近を要求しない。非常に容易な正例が1個あれば、別の正例のscoreが極端に低くてもlossはほぼ0になる。複数ビューすべての整合性を主張する場合には、平均正例NLLとは別の目的だと明記する。
- 観測上同じ未来を負例にも置くと、候補IDは違っても状態から識別できず、矛盾した課題になる。画素hash一致の除外だけでは近似同一状態・回帰を取り切れない。
- 既知の候補を背景やepisode固有情報で区別できるなら、後続の操作対象情報を捨ててもよい最適解が残る。同タスク負例は一つの緩和であって証明ではない。
- 潜在の一様な尺度増大は二乗距離score差を増幅し、正しく順序づけた分類を容易にできる。温度、MSE、SIGRegとの相互作用を無視して識別lossだけ比較してはいけない。

意味の異なる未来候補を区別しなければ損失を下げられない状況では、Bはその差を残す圧力を与える。しかし任意の後続タスクに必要な差まで候補集合が網羅するという仮定は置けない。

## 5. C：保持更新ゲート

### 5.1 自由なpに対しては表現能力ではなくパラメータ化の変更

```math
\hat z=z+g\odot(p-z).
```

任意のg_j>0と任意の目標写像fに対し、p=z+(f−z)/gとすれば同じfを表現できる。十分自由なpのもとでは、ゲートによって表現できる遷移の集合が本質的に増えたとはいえない。有限容量ではpの実装しやすさ・勾配・初期化による差はあり得る。

gが小さいことを物理的な非操作性と同一視できない。大きいp−zとの相殺で同じ出力を作れるためである。単純残差接続・固定gate・同程度の追加パラメータ対照が必須となる。

### 5.2 条件付きでゲートが有効な場合

1成分の候補差d=p−z、真の差Δ=y−zを固定したとき、制約0≤g≤1の二乗誤差最適値は、d≠0ならg*=clip(Δ/d,0,1)。d=0ならgate値によらず同じ誤差になる。

同じgate入力hを持つ例を平均し、候補生成器を固定した場合は

```math
g^*(h)=\operatorname{clip}\left(
\frac{\mathbb E[d\Delta\mid h]}{\mathbb E[d^2\mid h]},0,1\right)
```

となる（分母>0）。静止状態Δ=0に対する候補の誤更新を抑える合理性がある。ただし動作開始をhから区別できなければ、静止例の多さにより過保持する可能性がある。sigmoidでは境界0/1は有限logitで厳密には到達しない。実際のE/pも共同学習する問題の収束定理ではない。

### 5.3 安定性は自動ではない

現在zに対してpとgも変化する全微分は

```math
J_{\hat z}=I+\operatorname{diag}(g)(J_p-I)
+\operatorname{diag}(p-z)J_g.
```

独立の数値検算で一致した。固定スカラー0<g≤1でpがLipschitz定数L_p<1の写像なら、合成写像の定数は高々1−g+gL_p<1となる。g=0なら恒等写像で、厳密収縮ではない。一方p=2z、g=.1だけでも係数1.1の拡大型で、50回反復は約117.39倍になる。小さいgateだけでは安定性を示さない。

状態履歴を使う実LeWMでは、上式は現在状態ブロックの微分であり、全履歴の遷移安定性には拡張状態のヤコビアンを用いる必要がある。また永続情報は本来収縮させず保存すべき場合があり、全体の強制収縮を新しい目標にしない。

### 5.4 座標系への依存

非等方の対角gateは一般の直交回転と可換でない。2次元でdiag(.1,.9)を45度回転すると非対角成分の絶対値は.4になる。Gaussian正則化の回転対称性から、各潜在座標が物理要因になるとは導けない。

共同学習でgateに都合のよい基底を獲得する可能性はあるが、物体分解・独立機構を同定したという保証はない。Cはこの対称性を破る帰納バイアスとして説明する方が正確である。

## 7. 数学から導く採否条件

1. Aを本命候補にする場合も、残差の停止・観測ノイズ問題と平均の背景逃避を事前診断する。A+を足しただけで解決扱いにしない。
2. Bは候補規則によって何を区別せざるを得なくなるかを検証する。系列内外を混ぜた通常CPC対照、偽負例率、有効候補率が必要。
3. Cは観測潜在に必要情報があるか、予測で失うかを先に分ける。必要情報が観測側から欠けるならC単独を主要解にしない。
4. Raw対提案の100k比較は実用性能を測る。TC超えには同予算のTCが必要で、単一PushT結果をマルチタスクの証明にしない。
5. 数学的な成立、最適化できること、意味情報の保存、制御性能向上、新規性は別々の審査項目とする。どれか一つの通過を他の保証として扱わない。
