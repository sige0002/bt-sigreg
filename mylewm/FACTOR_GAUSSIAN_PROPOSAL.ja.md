# 初期仮説とアルゴリズム：関係保持型ブロックSIGReg（RBG v0）

更新日：2026-09-06。状態：初期研究仕様に基づく正則化と学習コードを実装し、PushT学習を開始した。[進行記録](RBG_EXECUTION_STATUS.ja.md)を参照。性能・新規性は未実証。RBGは本リポジトリ内の仮称であり、TC超えが確立した手法名ではない。以前のShape-free案に代わる本命候補とし、Shape-freeは診断対照として残す。

## 1. 研究仮説

H1：複数タスクの状態を共有する小型LeWMでは、全潜在の同時ガウス性を要求するより、少数のブロックの周辺ガウス性と弱いブロック間の線形重複抑制だけを要求する方が、操作に必要な非線形な関係を、小さな予測器で利用しやすい形に保持できる。

H2：この表現を状態全体の一段予測から学ぶと、時間残差だけを正則化するTCに比べ、静的な対象情報と動的情報を併用するLIBERO-10で改善し、PushTではRaw LeWMの性能を維持できる。

H1は分布・表現に関する仮説、H2は制御に関する仮説であり、どちらも未実証。H1からH2は自動的には導けない。小型性は設計で維持できるが、性能は実験で判断する。

「ガウス制約を緩めない」とは言わない。**各ブロックにはガウス制約を維持し、全体の同時分布に対する制約を選択的に緩める**。非ガウスの要因間依存を許すことが変更点である。

## 2. 数学的根拠と限界

独立なU∼N(0,1)、等確率のS∈{−1,+1}からV=SUとすると、U,Vはそれぞれ標準ガウス、Cov(U,V)=0だが、同時分布は二直線上にあり多変量ガウスではない。Sは原点を除きUVの符号から読み出せる。

したがって、周辺ガウス性と無相関性を保ちながら、関係に情報を格納できる。通常の全方向SIGRegはこの同時分布を母集団極限では許さない。これは表現可能性の例であり、符号Sがタスクになることを強制する方式でも、制御が改善する証明でもない。

重要な限界：ブロックを単位共分散へ近づけるため、タスク間・タスク内の分散競合は各ブロック内部に残る。ブロック間共分散も0へ近づけば全体共分散はIであり、二次統計の予算問題を解消したとは言えない。今回の初期仮説は、主に高次の同時分布制約と予測の容易さを対象とする。

## 3. モデル構造

- 公式比較と同じ画像エンコーダE、行動エンコーダA、単一の共有予測器Fを使う。総潜在次元Dを増やさない。
- 初期設定はD=192の場合K=4、各ブロックd=48。これは設計上の初期値で、物体数・タスク数には対応させない。
- Eの出力座標を固定の連続区間で分割する。既存Eの重みが、その座標へ何を表すかを学習する。追加の学習可能射影、別エンコーダ、K個の予測器、タスク別分岐は作らない。
- Fは全ブロックと実行行動を受け、次の全ブロックを一度に予測する。因子ごとの独立な遷移は仮定しない。
- ブロックを物理的な「要因」と呼べるかは診断結果次第である。座標の分割だけで物体や因果要因を同定したことにはならない。

## 4. 損失関数

通常軌道の履歴H_t、行動a_t、実測次画像o_{t+1}から、

\[
z_t=E(o_t),\quad \hat z_{t+1}=F(E(H_t),A(a_t)),\quad
L_{pred}=\frac1{TD B}\sum_{t,b}\|\hat z_{t+1,b}-z_{t+1,b}\|_2^2.
\]

Tは有効な一段教師の数。予測文脈長・画像と行動の時間幅はRawと同じ。教師側にも通常の勾配を流し、EMA・stop-gradientを追加しない。未来画像は教師と正則化にのみ使い、Fの文脈へ渡さない。

### ブロック周辺のSIGReg

\[
L_G=\frac1K\sum_{k=1}^K\mathrm{SIGReg}(Z^{(k)}),\qquad
Z^{(k)}\in\mathbb R^{T'\times B\times d}.
\]

T'はRawと同じ正則化対象の観測位置。各位置でB方向に統計を取る。全タスク混合のバッチを使い、タスクごとに同一ガウスへ一致させない。タスク別の平均除去も行わない。

射影はブロック内だけで毎回再抽選し、ブロックをまたぐ方向のGaussian検定は行わない。初期設定は合計1024射影を4ブロックへ256ずつ配分し、周波数17点・[0,3]はRawと共通にする。分割を毎回シャッフルしない。全方向を再び覆う変更は、緩めた同時ガウス制約を戻し得るためである。

### ブロック間の線形重複を抑える項

各観測位置でバッチ平均を引いたX^{(k)}から、

\[
C_{ij}=\frac{(X^{(i)})^\top X^{(j)}}{B-1},\qquad
L_X=\mathbb E_{t}\frac{2}{K(K-1)d^2}\sum_{i<j}\|C_{ij}\|_F^2.
\]

K=1ではL_X=0。B≥2が必要。入力をバッチごとに白色化してからSIGRegへ渡すことはしない。正則化の尺度逃避や意味の変化を避けるためである。

この項は同じ信号の線形コピーを抑えるが、非線形コピーまでは排除しない。相互情報量を0にする独立性損失は入れない。必要な相互作用を保存するためである。線形関係も物理的に有用な場合があるため、L_Xの重み0を必須対照にする。

最終的な初期目的は

\[
\boxed{L=L_{pred}+\lambda_G L_G+\lambda_X L_X.}
\]

初回の動作確認設定はλ_G=0.09、λ_X=0.01。最適値という主張ではない。比較ではRaw/TCのλにも同等の探索予算を与える。損失値だけでなくEへの各項の勾配ノルムを記録する。

## 5. 学習・推論手順

1. 軌道単位でtrain/validation/testを分離する。通常の観測・行動から未来時刻が正しいクリップを取得する。
2. 全タスクで共有するEで観測を符号化し、固定ブロックに分割する。
3. Fが履歴全体と行動から次のz全体を予測する。
4. 一段予測、各ブロックSIGReg、ブロック間共分散を計算する。
5. それらの和でE/A/Fを共同更新する。場面やタスクごとの新しい学習部品は追加しない。
6. 推論では分割・正則化の計算を不要とし、E/A/Fと元の潜在Goal距離・計画器を使う。

LIBERO-10は10タスク共有、タスク数の増加でモデルは増えない。データローダの混合比はRaw/TCと同じにする。PushTとLIBEROの観測・行動アダプタは各ベンチマークに合わせるが、各比較手法で共通化し規模へ計上する。両ドメインを一つの重みに統合する実験ではない。

## 6. TCを超える仮説と、超えられない場合

TCは潜在から時間平均を引いた残差へSIGRegを移す。本案は時間平均で捨てる成分を作らず、状態全体にあるブロックとその相互作用を予測する。[TC-LeWM](https://arxiv.org/html/2607.26924v3)

優位性の仮説：操作対象・容器位置・接触状態など、時間スケールが異なる情報の組合せが必要な場面で、全潜在の同時ガウス化を避けつつ安定した周辺分布を持てる。E/Fの規模を増やさず、その関係を予測に利用できればTCより有利になる。

反対仮説：TCが解いた動的分散の圧縮こそ主因なら、本案はそれを直接解かず負ける。静的背景だけで各ブロックの分散を満たすことも可能で、必要情報の保存は保証しない。関係を複雑にしすぎればFやGoal距離にとって不利にもなる。

単純な分割とL_Xでは「要因の複製を防ぎ、相互作用を守る」という前の議論を完全には解決していない。この限界を隠さず、最小の検証可能なv0として扱う。失敗時に補助損失を無制限に足さず、原因を判断する。

## 7. 先行研究との関係と新規性の扱い

Sub-JEPAは複数の固定ランダムな行直交射影で部分空間ごとのGaussian正則化を行う。本案の非重複座標ブロックは強く関連し、特殊・近接ケースになり得る。ブロック間のデータ共分散制約と、許す同時依存構造、マルチタスクでの検証を差分として調べる。「新しい名前だから革新的」とは主張しない。[Sub-JEPA §3](https://arxiv.org/html/2605.09241v1)

Orthogonal JEPAは学習可能基底、要因別予測枝、状態合成を用いる。本案は一つの元のFを保持し、追加予測枝や基底を作らない。基底行列の直交性と、データのクロス共分散の抑制も異なる。[Orthogonal JEPA §2](https://arxiv.org/html/2608.20065v1)

従ってv0は先行研究に基づく研究候補であり、新規性確立前。独自貢献の候補は、周辺ガウス性と関係保持の両立条件を明らかにし、少ない計算量でTCを超えるマルチタスク制御を実証することに置く。

## 8. 対照・合否判定

| 条件 | 役割 |
|---|---|
| Raw SIGReg、K=1 | 元実装への帰着を確認 |
| TC-SIGReg | 必須の性能比較 |
| Sub-JEPA | 部分空間正則化だけで説明できるか |
| RBG、K=4、λ_X=0 | ブロックGaussian化単独の効果 |
| RBG、K=4、λ_X>0 | 線形コピー抑制の効果 |
| RBGに全体SIGRegを再追加 | 自由にした同時依存が必要だったかの診断 |

再追加対照は正則化強度の交絡があるため、強度をそろえた探索なしに高次依存の因果効果を断定しない。K=2,8はv0の基本動作確認後の感度分析とし、タスク数に合わせてKを決めない。

数学・実装テスト：K=1で同じ射影を与えたRawと損失・勾配が一致すること、線形コピーでL_Xが正になること、U/Vの例では各周辺がGaussianでも混合方向が非Gaussianになることを確認する。SIGRegは原点崩壊で正の損失でも勾配0になり得るため、その性質が解消したとは扱わない。有限標本の共分散にも損失床がある。

表現評価：未見軌道で静的／動的状態の読み出し、タスク内・軌道内分散、線形・非線形ブロック予測可能性、全ブロックと単独ブロックの読み出し差を測る。ブロックを隠す試験は分布外入力の影響を受けるため補助診断にとどめる。非線形依存の存在だけで、物理関係の獲得とは判定しない。

制御評価：同じ学習・計画予算、独立学習3seed以上、共通初期条件でPushTとLIBERO-10を比較する。TCの論文値は凍結表現＋BCであり、自分たちのCEM成績と直接比較しない。TCも同じ計画器で再学習・評価し、BC再現は別トラックにする。

TCを凌駕したと主張する条件は、同条件のLIBERO-10でTCとの成功率差が正で、その不確実性も改善を支持すること。PushTでRaw維持という別条件も満たすこと。平均だけでなく各タスク、最悪タスク、パラメータ、メモリ、推論時間を報告する。点推定だけ勝った場合は「改善傾向」、区間が広ければ未確定とする。

棄却・修正条件：複製や背景符号化だけが増える、必要な静的情報が残らない、動的分散がTCより圧縮される、同条件でTCに勝てない、またはSub-JEPAと差がない場合には、対応する機構・性能・新規性の主張を取り下げる。これらは研究全体の不可能性ではなく、v0仮説の限界である。
