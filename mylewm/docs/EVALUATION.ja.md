# 4. 評価する

[前：学習](TRAINING.ja.md) · [入口へ戻る](README.md)

評価では、学習した世界モデルが**良い行動を選ぶために役立つか**を確かめます。学習誤差と、環境での操作成功率は別の指標です。

## 世界モデルを使って行動を選ぶ

CEMは候補の行動列を繰り返し改善する探索方法です。

1. 複数の行動列を候補として作る。
2. 世界モデルで、それぞれを実行した後の状態を予測する。
3. 目標画像から得た状態に近い候補を選び、その周辺を再探索する。
4. 選んだ行動を環境で実行し、新しい観測から計画し直す。

予測と目標までの距離には状態zを使います。BTの学習専用変換Tは使いません。

<a id="pusht"></a>
## PushTで評価する

学習で保存した`step_N_object.ckpt`を使います。入口は次のコマンドです。

```bash
bash scripts/evaluate_pusht.sh --help
```

[実行例](reference/CEM_AND_RENDERING.ja.md#pusht-2-新しいrawbt-runを評価する)でcheckpoint・データ・評価ケース・新規出力先を指定し、まず設定確認を行います。実際に環境を動かす場合だけ`--execute`を指定します。

成功は環境の成功判定で数えます。予測コストが小さいことや、Goal画像に似ていることを成功の代わりにしません。

## RawとBTを公平に比べる

同じ学習予算のモデルを、**同じ初期状態・Goal・CEM設定・成功判定**で評価します。BTだけ探索数を増やすと、世界モデルと探索量のどちらが効いたか分かりません。

見る項目は、成功数／試行数、同じケースでの成否の差、学習・推論時間です。複数学習seedでばらつきも確認します。公式配布モデルの成績と、同条件で再学習したRawの成績は分けます。

<a id="intermediate"></a>
## 結果を確認する

終了コード、結果ファイル、指定した試行数が一致していることを確認します。中断した残り試行を失敗扱いにしません。保存された動画は失敗原因の確認に使います。[出力の読み方](reference/CEM_AND_RENDERING.ja.md#pusht-6-終了と結果を確認する)

保存済みの途中checkpointも評価できます。最終更新だけでなく、事前に決めた途中更新でも成功率を比べると学習効率を調べられます。モデル間の生の潜在MSEだけで優劣を決めないでください。

## 他の評価との違い

| 評価 | 分かること |
|---|---|
| 世界モデル＋CEM | 予測を使った行動選択・制御の能力 |
| 記録済み軌道の予測 | 予測誤差や行動への依存性。環境成功率ではない |
| BC（行動模倣） | 学習した画像表現からデモ行動を出せるか。未来予測器は使わない |

<a id="libero"></a>
LIBEROはカメラ・行動・成功関数の対応を別途確認します。新256pxモデルの通しCEM評価には未確認部分が残ります。LIBERO・OGBench・BCの専用手順は[補足資料](reference/README.md)から参照してください。
