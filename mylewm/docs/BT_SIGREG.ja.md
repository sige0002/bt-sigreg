# 最有力研究案：有界可逆変換を用いたSIGRegの座標分離

2026-09-08更新：§1–8は提案時の論拠、§9は初期試作の監査履歴。現在の修正版は§10のCayley特異値構成。検証・実データ診断の実施状況は[検証記録](VALIDATION.ja.md)を参照し、歴史的な未実装の記述と区別する。

2026-09-07。仮称 **BT-SIGReg（Bounded-Transport SIGReg）**。新しい方式としての初出・SOTAは未確認。研究者役と数学者役の別AIエージェントの独立提案・反証を、主エージェントが統合した研究案。実在の専門家による査読ではない。実装・学習は開始していない。

## 1. 固定する目的

LeWMの目的は、報酬やタスク仕様を使わず、画像と行動の通常軌道から環境のダイナミクスを学び、後で多様なタスクに使えるコンパクトな世界モデルを得ること。本研究はこの目的を変えず、共有モデルで複数タスクを学習した場合の性能を改善する。[LeWM §3.1](https://arxiv.org/html/2603.19312v3#S3.SS1)

非操作物体保持、物体分割、タスクごとのルーティングを主目的にしない。これらを必須部品にも置かない。実装難易度は採否理由に使わない。小型性、学習の安定性、調整自由度、推論速度はLeWMの研究上の価値なので評価する。

## 2. 私たちが選ぶ中心仮説

**複数タスクの経験を共有するとき、「小さな予測器が遷移を表しやすい座標」と「標準Gaussianに従う座標」が一致するとは限らない。Gaussian化に必要な座標変換を予測器に背負わせず、学習時だけの可逆変換へ移すと、同じ容量の世界モデルでより精密にダイナミクスを学べるのではないか。**

これはGaussianがマルチタスクを原理的に禁止するという主張ではない。小容量・有限データ・一段予測との組合せでの、表現形状と予測のしやすさの問題である。マルチタスクで実際にこの問題が支配的かは未確認。

## 3. アルゴリズム

共有エンコーダ・予測器を維持し、学習時の正則化分岐だけに同次元の写像Tを置く。

```math
z_t=E_\theta(o_t),\qquad
\hat z_{t+1}=F_\phi(z_{\le t},A(a_{\le t})),\qquad
u_t=T_\psi(z_t),
```

```math
L=\mathbb E\left[\|\hat z_{t+1}-z_{t+1}\|^2/D\right]
 +\lambda\,SIGReg(U).
```

- 予測損失はzで計算する。Tを通した予測一致損失へ変更しない。
- SIGRegは従来と同じ時刻別バッチ統計、射影予算・統計精度を使う。
- Tは全タスク・全時刻・全サンプルに共通。タスクID、episode ID、Goal、行動、バッチ統計で条件付けない。乱数ノイズを入力して分散を捏造しない。
- E、F、Tを単一の目的で共同学習し、未来教師側のEにも勾配を流す。追加の識別損失・多段損失・画素復元・教師EMAを必須にしない。
- 推論ではTを使わず、zだけで既存のrolloutとGoal距離を計算する。訓練再開用checkpointにはTを保存し、推論用exportでのみ除外する。

```text
観測・行動 → E/A → z → F → 次のz → 潜在空間で計画
                   └→ 共通の有界可逆T → u → SIGReg（学習時のみ）
```

現在のLeWMにもprojectorはあるが、その出力を予測にも正則化にも使っている。本案ではその既存状態zを維持して分岐を追加する。単に既存projectorをTと呼び替える変更ではない。

## 4. 普通のMLPや無制約flowでは不十分

Tには固定された大域的な距離の上下界を要求する。

```math
m\|x-y\|\le\|T(x)-T(y)\|\le M\|x-y\|,
\qquad 0<m\le M<\infty.
```

上界Mがないと、`z=εs, T(z)=z/ε`によって正則化値を維持しながら、zでの予測MSEをε²倍へ縮められる。可逆性だけではこの逃げ道を防げない。m,Mは訓練中に無制限に学習させず、開始前に固定する。

一つの構成は残差写像`T_k(x)=x+g_k(x)`、`Lip(g_k)≤κ_k<1`の合成。

```math
m=\prod_k(1-\kappa_k),\qquad M=\prod_k(1+\kappa_k).
```

各ブロックの上界は三角不等式、下界は逆三角不等式、逆写像の存在は収縮写像による不動点構成で示せる。[Invertible Residual Networks](https://arxiv.org/abs/1811.00995)、[Residual Flows](https://arxiv.org/abs/1906.02735)

例として2ブロック、各κ=.2ならm=.64、M=1.44。これは性能を裏付けた推奨設定ではなく、非自明で有限な歪み予算の例。多層化で積の境界が緩くなることも記録する。原点漂いを抑えるためT(0)=0とする構成も候補だが、分散の証明自体は並進に依存しない。

実装でのLip制約は損失による緩い罰則とは区別する。重み行列のスペクトルノルムの上界と活性関数のLip定数を保証し、近似的なpower iterationの推定値だけを厳密な上界として扱わない。inverse計算やlog determinantの尤度項は今回の学習には必須でない。

## 5. 数学的に成立する主張

### 命題1：T自体では情報を削除しない

可逆なTに対してZとU=T(Z)は一対一に対応する。定義可能な相互情報量では`I(Z;Y)=I(U;Y)`。定数表現も`T(Z)=const ⇔ Z=const`で対応する。ただしEが観測から捨てた情報は回復しない。

### 命題2：正則化座標の分散から状態側の分散を制約する

有限二次モーメントを持つ独立コピーZ'を使うと、

```math
2\operatorname{tr}\operatorname{Cov}(Z)=\mathbb E\|Z-Z'\|^2.
```

距離の上下界を二乗して期待値を取れば、

```math
\frac{\operatorname{tr}\operatorname{Cov}(U)}{M^2}
\le \operatorname{tr}\operatorname{Cov}(Z)
\le\frac{\operatorname{tr}\operatorname{Cov}(U)}{m^2}.
```

特に**理想的に**Uが標準d次元Gaussianなら、

```math
\frac d{M^2}\le\operatorname{tr}\operatorname{Cov}(Z)\le\frac d{m^2}.
```

これは全体分散の命題で、各座標の分散下界やタスク内情報保持の命題ではない。有限射影SIGRegの値が小さいことだけから、UがGaussianという前提を満たしたと結論してはいけない。実測ではU/Z両側の分散、スペクトル、正則化値、写像の制約を独立に記録する。

### 命題3：単純な遷移でも座標により予測関数は変わる

状態側の遷移をf_zとすると、正則化座標での遷移は`f_u=T∘f_z∘T^{-1}`となる。例えば1次元で`T(z)=z+c sin(z), 0<c<1`は(1−c,1+c)-bi-Lipschitzで、状態側の`f_z(z,a)=z+a`に対応する遷移は

```math
f_u(u,a)=T(T^{-1}(u)+a),\qquad
\frac{\partial f_u}{\partial u}
=\frac{1+c\cos(T^{-1}(u)+a)}{1+c\cos(T^{-1}(u))}.
```

一般のaでは微分がuに依存し、元は線形だった遷移が非線形になる。この例は座標が予測関数の複雑さを変え得ることを示すだけで、この遷移の全時刻の周辺分布がGaussianであることや、実データで本案が勝つことを示さない。

### 成立しない強い結論

T=Iを許せば目的関数の最適値はRawより悪くないが、汎化・制御成功率・同更新数での性能は保証されない。Tが別座標でGaussianを作っても、Eが背景だけを残す解や、少数タスクの情報を捨てる解は残り得る。完全崩壊点からの大域的脱出保証を新たに得たとも言わない。

## 6. 研究者・数学者の討論

**研究者役：** 小型Fに複数の遷移を学ばせたい。状態の幾何を固定Gaussianへ合わせる圧力と、予測しやすい座標を選ぶ圧力を分ける方が、物体保持やタスク別部品より目的に直接対応する。

**数学者役：** 普通の可逆headでは尺度逃避がある。Mを固定しない案は採用できない。上下界があれば上記の分散命題は成立するが、Gaussian性の有限標本保証や意味情報の十分性へ拡張してはいけない。

**研究者役の反論：** Tが分布合わせを全て吸収しただけで、小さいMSEを成功と扱う危険がある。固定尺度・アフィンheadとの比較で、非線形形状の効果を切り分ける必要がある。状態側のGoal距離が良いことも未保証。

**主エージェントの判断：** 上下界を設計条件に含め、非線形座標分離の効果を同容量・同条件の制御で反証可能にする案を第一候補にする。ABCはそのまま本命にせず、必要な対照や別仮説として残す。選択理由は実装の容易さではなく、LeWMのGaussian非崩壊原理を残して、共有ダイナミクスに対する制約を直接変えられること。

## 7. ABCと先行研究との差

- Aは時間平均／残差に分解する。今回は時間分解を要求せず、静止窓にも非零の時間変化を要求しない。
- Bは候補未来の識別目的を加える。今回は負例もタスクグループも使わず、予測＋正則化の二項に留める。
- Cは予測出力の保持更新を変える。今回はFの出力構造を変えず、Gaussian制約をかける座標を変える。
- [TC-LeWM](https://arxiv.org/abs/2607.26924v3)は正則化の対象を時間残差へ移す先行。本案の共通可逆変換とは異なるが、マルチタスク性能の主要対照。
- [Sub-JEPA](https://arxiv.org/abs/2605.09241)は固定部分空間への正則化。本案は同次元・学習可能・可逆・大域的歪み制約付きという違いがある。
- [LpWM公式実装](https://github.com/YilunKuang/lpworldmodel)は疎な非負分布への分布合わせを使う。本案は別の固定分布に置換するのでなく、Gaussianの適用座標を変える。
- [The Geometry of Projection Heads](https://arxiv.org/abs/2605.17180v1)はheadが表現と損失の幾何を分離するという直接関連の理論。**座標を分ける発想自体を新規とは呼べない。** 今回確認した要旨と本文構成だけでは、LeWMにおける同じ有界可逆Gaussian分岐が既出かどうかを完全には判断できない。
- i-ResNet/Residual Flowsの可逆性も既存技術。新規性の候補は、予測と正則化の座標分離に必要な歪み制約の分析と、小容量マルチタスク世界モデルにおける性能・効率の実証にある。

追加のterra検索はエージェントのスレッド上限で開始できなかったため、今回の新規head/flow文献照合は主エージェントが実施した。過去のterraのABC文献調査と混同しない。完全な新規性調査ではない。

## 8. 棄却条件と比較計画

主比較は同じ新規初期E/A/F・同じデータ順・同じ100,000更新のRaw、TC、提案。タスクIDをworld modelへ入力しない。PushTの性能と、LIBERO-10の10タスク共有モデルの平均・タスク別・下位タスク性能を評価する。TC論文のBC成績と本実装CEMの成功率は直接比較しない。

機構の対照はT=I、固定スカラー、歪み制約付きアフィン、普通のMLP、可逆だが無制約の写像、歪み制約付き非線形写像。全部を自動学習キューに入れる意味ではなく、新規性と因果を主張するために必要な比較を列挙したもの。

次の場合は提案を棄却または単純化する。

1. 改善が潜在尺度縮小や固定アフィン変換だけで説明できる。
2. MSEやGaussian適合だけが改善し、同じCEMで成功率が改善しない。
3. 多数タスクの改善が少数タスクの大幅悪化と引換えになる。
4. 検証条件・seed・歪み予算を少し変えると改善が消え、過剰な調整に依存する。
5. 正則化器の訓練計算量だけを増やした効果で、同実測計算予算では優位がない。

固定されたbi-Lipschitz写像では任意の分布をGaussian化できない。離散・特異支持、コンパクト支持、強いtail差等には制限がある。m,Mを緩めれば自由度は増すが尺度逃避への保護は弱くなる。これを「任意のマルチタスク分布に対応」とは主張しない。

**結論：現時点の第一候補はBT-SIGReg。最良と証明されたモデルではなく、目的を維持し、数学的な設計条件を持ち、SOTAを狙う上で検証価値が最も高いと判断した研究仮説である。** 推論パラメータ増加0は設計上可能だが、新しい訓練モジュール・統合テスト・実験は未実施。

## 9. 実装（2026-09-08）

本節は旧Frobenius試作の履歴。現行コードは§10へ置換した。

`mylewm/bt_sigreg.py` の各ブロックを次で構成した。

```math
\bar W=\frac{W}{\sqrt{1+\|W\|_F^2}},\qquad
g(z)=\kappa(1-10^{-4})\bar W_2\tanh(\bar W_1 z),\qquad T_k(z)=z+g(z).
```

作用素ノルムはFrobeniusノルム以下なので、実数演算では常に `||W̄||₂ < 1`。tanhは1-Lipschitzで、`Lip(g) <= κ` が解析的に従う。バイアスなしのため `T(0)=0`。任意の有限重みの更新後も同じ構成を使い、power iterationや有限標本の距離罰則に依存しない。

これは保守的な上界で、スペクトルノルムを直接制約する方式より変形能力が弱くなる可能性がある。強度・幅・深さは未調整。数学上の上界は実数演算についてのもので、FP32の丸め誤差まで厳密保証する区間演算実装ではない。安全係数と数値テストを理論保証の代わりにしない。

W1を直交初期化、W2を0として、T全体を恒等写像から開始する。初回はW2に勾配が入り、その更新後にW1にも勾配が入る。両方の重みを0にする初期化ではない。depth=0は学習パラメータなしの恒等対照。

既定dim=hidden=192、depth=2、κ=.2ではTの学習パラメータ147,456、理論距離境界m=.64、M=1.44。推論用ネットワークの追加パラメータは0。TとSIGRegはautocast外のFP32（数学テストのTはFP64可）で計算する。

両trainerのbtモードは一段予測を元のzで計算し、全潜在に共通Tをかけた後、Rawと同じ1024射影・17周波数・時刻別バッチ集計のSIGRegを使う。cross項の係数は0。E/A/Fの構造・計画コードは変更しない。Tは学習専用optimizerグループとregularizer stateへ保存し、推論exportには含めない。Raw/TCの処理は維持する。

### 独立レビューで判明した表現力の制限

この実装は一般的なBTを代表する完成形ではなく、制限の強いFrobenius試作である。研究者役・数学者役の2体のAIが独立に検算し、相互確認した。

1. バイアスなしtanhにより `T(-z)=-T(z)`。可逆性から、Zが原点対称であることとT(Z)が原点対称であることは同値。非原点対称なZをこのTだけで厳密な標準Gaussianにはできず、encoderに対称化の負担が残る。原点固定だけから必要になる制約ではない。またtanhの有界性によりT(z)−zも大域的に有界となる。
2. Frobenius正規化は作用素ノルムに加えて `||Jg||_* <= κ`（核ノルム）まで制限する。行列積の展開より `||JT-I||_* <= ∏(1+κ_k)-1`。既定値では総予算は.44で、192次元の局所変形 `JT=1.1I` に必要な19.2を許さない。この変形は一般の距離境界[.64,1.44]なら許される。幅を増やすだけでは改善しないが、固定低ランク写像という意味ではない。

したがって、この試作が性能比較で負けてもBT仮説全体を棄却できない。性能学習前にこの制限を採用するか、原点固定と上下距離境界を保ちながら写像を再設計するかを研究判断する必要がある。今回のレビューではアルゴリズムを無断変更していない。

検証範囲と限界は[検証記録](VALIDATION.ja.md)を参照。小型マルチタスク性能の改善は未検証である。

## 10. 修正版：原点固定・非対称変形・特異値直接制約

ユーザー承認の修正として、各ブロックを次へ変更した。

```math
T_k(z)=z+\kappa(1-10^{-4})B\{\phi(Az+b)-\phi(b)\},
\qquad \phi(x)=\tfrac12 x+\tfrac12\tanh(x).
```

学習可能なbを非零で初期化する。T(0)=0は維持するが、Tが奇関数であることは強制しない。線形成分により、T(z)−zが必ず有界という旧tanh固有の制約も外す。ただし任意のtailや分布をGaussianに変換できるわけではない。

行列A,Bをそれぞれ `Q_left diag(tanh(s)) Q_rightᵀ` として構成する。矩形行列ではr=min(input,output)本の直交列を使う。Qは上三角の独立パラメータから作る歪対称行列Sについて `Q=(I-S)⁻¹(I+S)`（Cayley変換）。実数演算でQᵀQ=I、特異値は|tanh(s_i)|≤1なので、作用素ノルム上界が構成から従う。Frobenius正規化・power iteration・SVD推定は使わない。有限Cayley座標は単一chartであり、全直交行列を有限パラメータで網羅すると主張しない。

φの導関数は[.5,1]内、従って `Lip(g_k)≤κ`。旧版と同じ収縮写像の議論で可逆性と全体距離境界 `m=∏(1−κ_k), M=∏(1+κ_k)` を維持する。一方、旧核ノルム上界 `||Jg||_*≤κ` は不要になる。数値証拠では12次元すべての局所特異値を1.1より大きくし、核ノルム差が旧予算.44を超えても距離境界内にあることを確認した。同じ対角構成は192次元にも拡張できるが、任意の有界写像の表現保証ではない。hidden<dimの場合は各残差のランク制限が残る。

入力特異値を.8、出力特異値を0で初期化してT=Iから始める。初回は出力の特異値パラメータに勾配が入り、左右回転・入力側・biasへの学習は出力更新後に始まる。初回の接空間は任意のdense行列更新と同一ではない。勾配飽和や座標による最適化への影響は残る評価項目。

既定dim=hidden=192、2ブロックの訓練専用パラメータは147,840（旧147,456＋bias384）。推論追加パラメータ0、E/A/F・一段予測・SIGRegの射影予算は維持。FP32のsolveを使うため、解析保証は実数演算についてであり厳密な浮動小数点証明ではない。

configは `normalization=cayley_spectral_v2` と活性化・初期化方式を保存する。旧Frobenius checkpointとの互換性はなく、新規学習のみとする。新規性・制御性能の改善はこの実装修正だけでは示されない。
