# 1. アルゴリズム：BT-SIGRegが学ぶもの

[文書一覧](README.md) → アルゴリズム → [実装](IMPLEMENTATION.ja.md) → [学習](TRAINING.ja.md) → [評価](EVALUATION.ja.md)

## 世界モデルとは

ロボットのカメラ画像をそのまま予測する代わりに、画像を短い数値ベクトルへ変換し、その変化を予測します。このベクトルを**潜在状態z**と呼びます。例えば、物体やグリッパーの位置・状態の変化が、予測に役立つ形で表現されることを期待します。各成分に人が意味を割り当てるわけではありません。

| 記号 | 役割 |
|---|---|
| o | 実際に観測した画像 |
| E | 画像encoder。画像から特徴を取り出す |
| P | projector。画像特徴を予測用の状態zに変換する |
| A | 行動encoder。行動を予測器の入力へ変換する |
| F | 予測器。過去の状態と行動から次の状態を予測する |
| T | BTの学習専用写像。正則化用の座標uを作る |

LIBEROでは2台のカメラに同じEを使い、各カメラのCLS特徴を連結してPへ渡します。10タスクでE・P・A・Fを共有します。世界モデルには報酬、タスクID、Goal画像を入力しません。

## なぜ予測誤差だけでは足りないか

学習の基本は、予測した状態と、実際の次画像から得た状態の差を小さくすることです。

$$z_t=P(E(o_t)),\qquad \hat z_{t+1}=F(z_{t-h+1:t},A(a_{t-h+1:t}))$$

$$L_{\mathrm{pred}}=\mathrm{MSE}(\hat z_{t+1},z_{t+1})$$

しかしEがどの画像も同じベクトルへ変換すると、画像を理解しなくても誤差を小さくできます。これが**表現の崩壊**です。SIGRegは、バッチ内の特徴をランダムな方向へ射影し、その分布を標準Gaussianに近づける正則化です。予測損失と併用します。教師側の未来画像encoderへも勾配を流します。

## Raw・TC・BTの違い

| 方式 | SIGRegを適用するもの | 予測に使うもの |
|---|---|---|
| Raw | 状態zそのもの | z |
| TC | 時間窓の平均を引いた残差 | z |
| BT | 学習専用写像を通したu=T(z) | z |

BTの目的関数は次の形です。

$$L_{\mathrm{BT}}=L_{\mathrm{pred}}+\lambda\,\mathrm{SIGReg}(T(z))$$

BTの狙いは、崩壊を防ぎながら、z自体の分布の形に自由度を持たせることです。「どんなデータでもGaussianにできる」「制御性能が必ず上がる」という保証ではありません。

## Tに距離の上下界を設ける

Tが自由に拡大できると、zを縮めて予測誤差を下げ、Tで拡大して正則化だけを満たす抜け道ができます。そのため、Tにはあらかじめ固定した距離の上下界を設けます。

$$m\lVert z-z'\rVert \leq \lVert T(z)-T(z')\rVert \leq M\lVert z-z'\rVert$$

現行BTは、収縮性を持つ残差gを使った `x → x + g(x)` を重ねます。Cayley変換と特異値の制約により各残差のLipschitz定数をκ以下に制限します。既定は2ブロック・κ=0.2で、解析上の距離係数はm=0.64、M=1.44です。

この境界は実数演算における設計上の性質です。浮動小数点の厳密証明、タスク内情報の保存、成功率、最適化の収束の保証ではありません。現行Cayley v2は旧Frobenius版のcheckpointと互換ではありません。導出・初期化・制約は[詳細仕様](research/BT_SIGREG.ja.md)を参照してください。

## 学習後の2つの使い方

**CEMで制御する場合**は、候補の行動列をFで予測し、Goalとの距離が小さい列を探します。予測とGoal距離はzで計算し、Tは使いません。探索数や反復数も成功率に影響します。

**BCで制御する場合**は、Eを凍結して画像特徴から行動列を出す方策を別に学習します。現在のLIBERO方策は2カメラのCLS＋poolしたpatch特徴を使い、タスクIDを受け取ります。P・A・F・TはBC推論に使いません。したがってBCの成功率は、画像表現と追加方策の組合せの評価であり、Fの予測精度を直接測る値ではありません。

Tは推論から除きますが、学習再開にはTとoptimizerの状態が必要なので保存します。

## 何を実験で確かめるか

予測lossの低下、正則化の値、CEMの予測コストだけでは操作成功を示せません。環境での成功率、タスク別の成績、seed間の変動、学習時間と推論時間を確認します。Raw／TC／BTを比較するときは、データ・初期値・予算・制御方法を揃えます。

BTの制御上の優位性は未実証です。研究の背景と一次資料は[研究レビュー](research/RESEARCH_REVIEW.ja.md)、実測範囲は[検証状況](VALIDATION.ja.md)にまとめています。
