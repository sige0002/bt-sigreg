# BT-SIGReg

画像と行動の記録から、「この行動で状態がどう変わるか」を予測する小型の世界モデルを学ぶ研究リポジトリです。LeWMを基準に、正則化を変更したBT-SIGRegが予測と制御にどう影響するかを調べます。

初めて読む方は、次の4章を順に読んでください。

| 順番 | ガイド | 内容 |
|---|---|---|
| 1 | [アルゴリズム](mylewm/docs/ALGORITHM.ja.md) | 世界モデルとは何か、LeWMとBTの違い |
| 2 | [実装](mylewm/docs/IMPLEMENTATION.ja.md) | データの流れと、まず読むコード |
| 3 | [学習](mylewm/docs/TRAINING.ja.md) | PushTを例にデータ準備・学習・保存を行う |
| 4 | [評価](mylewm/docs/EVALUATION.ja.md) | 世界モデルで行動を選び、成功率を比較する |

BCの追加学習は必須ではありません。基本の流れは「世界モデルを学習 → CEMで行動を探索 → 環境で成功率を測る」です。BTがRawより優れるかは実験で検証します。

実装は`src/mylewm/`、設定・テスト・文書は`mylewm/`、比較用LeWMは`lewm/`にあります。データ・重み・生成ログは`output/`と`.cache/`に保存し、Gitには含めません。

別環境の手順や過去の実験が必要になったら、[文書の入口](mylewm/docs/README.md)から補足資料を参照してください。
