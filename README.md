# 複数タスクの経験から共有世界モデルを学ぶmyLeWM

更新日：2026-09-06

**研究目的は、通常の観測・行動経験から、複数タスクで再利用できる世界の状態表現と遷移規則を一つの軽量LeWMに学習させることである。** 現在の操作対象だけでなく、後続の別操作に必要な状態情報も保持し、撮影条件が変わっても必要な物理的な違いを認識できることを目指す。

**対象はPushTとLIBERO-10。LeWM程度のモデル規模を維持しながら、SIGRegの単一等方ガウス分布への正則化を見直し、高精度なマルチタスク制御と性能向上を目指す。** 多段予測損失の追加を、この課題への回答とはしない。

状態：初期候補[関係保持型ブロックSIGReg（RBG v0）](mylewm/FACTOR_GAUSSIAN_PROPOSAL.ja.md)を実装し、PushTの新規学習を開始。性能維持・マルチタスク能力はまだ未実証。[進行記録](mylewm/RBG_EXECUTION_STATUS.ja.md)と[実行方法](mylewm/README.md)を参照。旧実装・実験を現行提案の完成品として扱わない。

## 研究で実現したいこと

例えば、赤い物体を動かした後も青い物体の位置を内部状態に保持し、その予測状態から青を動かす結果まで予測できるようにする。別々のタスクで得た経験が、一つの世界の状態と変化の規則として利用できることが重要である。

| 要件 | モデルに求める機能 |
|---|---|
| 状態差の保持 | 同じ行動でも初期状態が違えば、その違いに応じた未来を予測する |
| 行動差の保持 | 同じ状態から異なる行動を与えたとき、実際の結果の違いを予測する |
| 後続操作に必要な情報の保持 | 現在は操作していない対象も、後の操作に必要なら予測状態に残す |
| 撮影条件への頑健性 | 照明・背景などへの依存を減らし、操作に必要な物理状態の違いは失わない |
| タスク間の再利用 | ある操作の予測終点を、実測未来の再入力なしに別操作の予測始点として使う |
| 未経験の組合せへの一般化 | 学習済みモデルを固定し、未見配置・操作順序へ既知の規則を使う |

パラメータ共有、訓練lossの低下、候補未来の識別精度だけを、これらの達成とはみなさない。PushT単体で成功しても、複数タスクへの再利用を実証したことにはならない。

## 学習の前提と設計方針

入力の基本単位は、各タスクで通常得られる観測履歴・実行行動・実測結果の系列とする。人間が全ての「初期状態×行動」の組合せを実行し、交差対応表やタスク間の一対一対応を用意することを必須条件にしない。

経験から共通の規則を学ぶことを目的とし、記録されていない分岐をモデル生成や画像複製で実測教師として扱わない。未知の行動結果を全て自動的に知れることを意味するわけではなく、経験の範囲と一般化できる範囲を評価で区別する。

共有の画像エンコーダE・行動エンコーダA・予測器Fを出発点とする。タスクごとの別クラスタを作ることや、Goalに合わせて現在不要な情報を捨てることを目的にしない。タスクIDは予測器への必須入力にせず、Goalは計画で何を達成したいかを指定する役割として整理する。

中心課題は、SIGRegの高次のガウス形状制約と、タスク間・タスク内の分散配分が、小型モデルの必要情報保持にどう影響するかである。「ガウスではマルチタスクが不可能」とは断定せず、一段予測とE・A・Fを固定した比較で検証する。

本命の初期候補は、各潜在ブロックのガウス性を保ち、要因間の非線形な依存を許すRBG v0。単一のE/A/Fと一段予測を維持し、追加推論パラメータは0とする。TCおよびSub-JEPAを必須比較に置く。以前のShape-freeは診断対照へ位置付けを変更した。[初期仮説・アルゴリズム仕様](mylewm/FACTOR_GAUSSIAN_PROPOSAL.ja.md)と[研究レビュー](README_RESEARCH_REVIEW.ja.md)を参照。新規性・性能向上は未確立である。

## 検証と成功条件

最初の制御評価には既存のPushTデータを使う。公式LeWMを比較対象として保存し、開始状態・Goal・成功判定・観測と行動の前処理・CEM予算をそろえる。初期重み、学習データ、更新数、計算量、乱数seedも記録する。公式重みからの追加学習と、ランダム初期化からの学習は別の実験として報告する。

PushTで公式から性能を落としていないことを入口の検証条件とする。ただし、有限回の試行で任意の状況に対する性能維持を保証することはできない。観測された成功率差と、その不確実性を区別して報告し、許容低下幅を結果を見て変更しない。

LIBERO-10では10タスクを一つの共有世界モデルで学習し、同条件のRaw LeWMとの平均・各タスクの成功率、規模、計算量を比較する。PushTの維持に加えてマルチタスク性能の向上を目指す。非操作対象の情報保持や未見配置への再利用も調べ、パラメータ共有と世界の状態・遷移の再利用を区別する。

## 実装・実験の現状

| 検討・実験 | 現在の扱い |
|---|---|
| 同時刻教師と複製ビューを使った旧50,000更新 | 未来予測の学習として不適切。研究比較に使わず、旧myLeWMチェックポイントは削除済み |
| 初期状態×行動の交差対応表方式 | 過去の設計案。対応表を必須としない現在の要件を満たさず、完成方式ではない |
| 公式LeWM＋SIGReg＋多段予測損失の追加学習 | 現在の研究案として不採用。SIGRegを見直す仮説の検証ではない |
| 関係保持型ブロックSIGReg（RBG v0） | 正則化・学習コード実装、単体テスト済み。PushT学習中、制御性能は未検証 |

多段予測追加実験のローカル予備評価では、同一50試行で公式45/50（90%）、追加学習モデル39/50（78%）だった。この実験は性能維持条件を満たしておらず、研究目的の達成を示すものでもない。また、これを研究アイデア全体の反証とは扱わない。200試行の確認評価は、このREADME更新時点では最終集計を記載していない。

この予備評価は、使用中のPushT環境におけるデータセット由来のGoal状態への到達評価である。手先と物体の位置差のノルムが20未満、物体角度差がπ/9未満という判定を使い、固定T目標への95%被覆率の評価とは同一視しない。評価エピソードは追加学習から除外したが、公式チェックポイントにとっても未見だったとは主張しない。実験コード・生ログは今回のREADMEのみのコミットに含まないため、この記述だけで再現可能な公開実験一式がそろっているという意味ではない。
