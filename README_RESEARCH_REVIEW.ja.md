# LeWMのマルチタスク世界モデル化：研究目的・学習原理・実現可能性の検討レポート

作成日：2026-09-05。対象は [README.md](/home/USER/task-centered-sigreg-lewm/README.md) の現行版、コミット 1b9ee0b。理論・表現学習、ロボティクス実験、査読・実験設計の三つのペルソナによる独立レビューと再討論を、研究責任者の立場で統合した。討論は内容を編集した模擬討論であり、実在の専門家による査読ではない。

**研究目的は、LeWMが複数タスクの経験から、自ら予測と操作に使える世界の表現を学び、一つの世界モデルとして再利用できるようにすることである。** 交差データの収集や負例の選び方は、そのための手段である。それらの有効性を示すだけでは、この研究目的の達成にはならない。

**総合判定は「目的と共有LeWMの方向性は整合しており、研究として実現可能性がある。ただし、現行READMEの学習目的だけで、タスクをまたいで再利用できる世界が形成されるとはまだ判断できない」である。** 特に必要なのは、ある操作で獲得した状態認識を、別の操作の未来予測へ接続できることの定義と検証である。

確認時点のリポジトリにはREADMEのみがあり、学習コード・データ・結果はない。以下では、READMEに書かれた設計、そこから導く分析、新たな検討案を区別する。学習成功、必要計算量、新規性を実証したレポートではない。

**「自分の認識する世界」を、モデルの機能として定義する。** 学習したいのは、経験を受けて「何がどのような状態にあり、この行動をすると何が変わり、何が残るか」を内部表現として扱えるモデルである。物体位置や接触といった人間の言葉は、獲得した表現を説明・評価するために使う。潜在の各次元へ、その意味を最初から人間が割り当てる必要はない。

例えば赤を動かした後、青がどこに残っているかを内部状態に保持する。その状態から、赤をもう一度動かす未来も、青を動かす未来も予測できる。さらに、赤を動かす経験から学んだ変化の規則が、条件の共通する別の物体や配置でも役立つ。ここに、複数タスクの経験を一つの世界へ統合する意味がある。

ただし、経験から認識できない状態や、一度も根拠が得られなかった物理法則まで自動的に獲得するという意味ではない。対象とする操作群について、観測・履歴から推定でき、未来を左右する情報を学習することを目標とする。

| 比較する性質 | 達成している内容 | それだけでは分からないこと |
|---|---|---|
| 複数タスクで同じネットワークを訓練 | パラメータを共有している | 内部で経験を別々に処理している可能性 |
| 複数タスクで高い予測精度 | 各経験の予測に対応できる | 他タスクへ状態や変化の知識を再利用できるか |
| 一つの予測状態から複数の操作を予測 | 状態を異なる行動へ利用できる | 未見の配置・操作順序にも接続できるか |
| モデルを固定して未見の組合せを予測・操作 | 学習した世界を再利用できる | 学習範囲外の任意の物理や長期記憶まで成立するか |

内部の意味が人間の物理概念と一対一に一致することは必須ではない。研究上まず求めるのは、異なる経験をつなぎ、複数の操作を予測できるという機能上の共有である。

**ペルソナ別の見解。**

| ペルソナ | 主な評価 | 重要な懸念 |
|---|---|---|
| 理論・表現学習研究者 | 共有表現と行動条件付き予測は、経験から世界を形成する目的に合う | 表内の識別から、経験をまたぐ一貫した予測状態までは保証されない |
| ロボティクス実験担当 | 同一ロボット・同一行動形式の小規模な複数操作なら実装へ進める | 状態・履歴・行動座標・自己回帰時の情報の扱いが未確定 |
| 厳格な査読者 | 研究目的は妥当。単純な混合学習を超える共有と再利用を示す必要がある | 四択精度やデータの効果だけを、世界モデルの成功とみなせない |
| 研究責任者・統合役 | 研究の主題を共有世界モデルの学習原理に置く | SIGReg除去や収集手順が目的を置き換えないようにする |

**討論1：同じLeWMで複数タスクを学べば、共通の世界ができるのか。** 対象はREADME §1–3、§15。

理論研究者：同じE・A・Fを使うことは出発点として合理的である。しかし、一つのネットワークでも、赤を操作する経験と青を操作する経験を内部で別々に覚えることはできる。タスクIDを渡さなくても、配置や行動の傾向から経験の種類を推定して処理を分けられる。

研究責任者：それなら、共有世界として何ができればよいか。

理論研究者：赤の操作で予測した「操作後の状態」を、そのまま青の操作を予測する「操作前の状態」として使えることが重要である。あるタスクの終点と別タスクの始点が、一つの状態と遷移の体系として接続する必要がある。

査読者：学習済みモデルを固定し、既知の操作を未見の配置や順序へ組み合わせて予測させたい。そこで毎回タスク別の再学習を必要とするなら、共有の度合いは限定的である。また、異なる経験から到達した同じ予測上の状態に、同じ継続行動を与えたとき、未来が整合するかも重要になる。

実験担当：最初から新しい大規模モデルを作る必要はない。既存の共有E・A・Fで、赤→青、青→赤、押す→別方向へ押すといった接続を調べられる。目標や段階切替は全手法でそろえ、世界モデル自体の予測と再利用を比較する。

統合判断：マルチタスク化の中心は、ネットワークの共有に加えて、**状態と遷移をタスク間で使い回せること**にある。現行READMEには共有構造がある。次に必要なのは、タスクをまたぐ予測状態の互換性を、学習と評価の要件として具体化することである。内部ベクトルの完全一致を無条件に求める必要はないが、後続操作に対して矛盾する世界を作ってはいけない。

**討論2：モデルは、何を残し、何を捨てるかを学習できるか。** 対象はREADME §3–5、§8–12。

研究責任者：赤の操作中に青を残すことを人間が一つずつ決めるのではなく、複数タスクの経験から、世界の状態として必要な情報を学んでほしい。

理論研究者：行動条件付き予測は、そのための合理的な学習信号である。ある違いを捨てた結果、複数の操作の未来を正しく予測できなくなるなら、その違いを内部に残す圧力が生じる。一方、照明だけが違っても同じ行動結果へ対応するなら、その違いへの依存を減らす圧力が生じる。

査読者：ただし、教師の潜在表現も同時に学習されるため、予測しにくい要素を入力側と未来側の両方から消せば、予測誤差を小さくできる。複数タスクを混ぜるだけで、将来必要な要素が必ず残るわけではない。

理論研究者：その通りである。必要なのは、単なる予測誤差の最小化に加え、異なる結果を同一視して解くことを抑える仕組みである。現案の識別損失はその候補だが、選ばれた候補で問われない情報までは守らない。

統合判断：READMEの「物理状態・行動による違いは残し、撮影条件だけの違いへの依存を減らす」という方向は、世界の表現を学ぶ原理として妥当である。ただし、非崩壊と必要情報の保持は同じではない。SIGRegで表現が広がっていても必要な物体情報が残るとは限らず、識別課題に成功していても同様である。

目指すべきなのは、現在のタスク成功だけで状態をまとめることではなく、対象とする複数の後続操作について、結果を左右する区別を保つことである。箱入れでは同じ成功状態でも、取り出し結果が違うなら、世界モデルには違う状態として扱える情報が必要になる。README §9.2の考え方は、この目的に合っている。

学習時に物体位置等のラベルを与えない構成でも、その情報が獲得されたかを評価時の読み出しで調べられる。「人間が状態を入力すること」と「学習された状態を人間の指標で検証すること」は分けて考えるべきである。

ただし、現行READMEでは正例集合の判定に保存物理状態等を使う場合があり、その対応情報は追加の教師情報に当たる。内部表現を端から端まで学習することと、学習課題の構成に教師情報を使わないことは同じではない。

**討論3：現行の交差予測損失は、世界形成に十分か。** 対象はREADME §9、§12、§19。

査読者：現行損失は、同じ表の中で正しい未来を選ぶことを要求している。しかし、四つの未来を「青の初期位置」と「行動ごとの終端手先姿勢」だけで識別できれば、赤の接触や移動を予測せずに解ける場合がある。表全体を比較しても、この近道は残る。

理論研究者：また、表の中では区別できても、別の表に同じコードを再利用することは直接には罰されない。例えば二つの領域で相対配置と相対的な遷移が同じなら、領域の違いを捨てた表現が両方を解ける場合がある。絶対位置が後続操作に必要なら、それは共有世界として不足している。

研究責任者：では、交差予測という考えを捨てるべきか。

理論研究者：捨てる根拠はない。状態と行動の両方を使わせる局所的な学習圧力としては有効な候補である。ただし、それを世界モデルの定義そのものにしてはいけない。評価するべきなのは、そこで得た状態が別の経験の予測にも使えるかである。

統合判断：**現在の識別損失は、共有世界モデルを育てるための補助原理の候補であり、その成立証明ではない。** 損失や学習方法の価値は、表内の識別率よりも、タスクをまたぐ状態認識、実際の物体変化の予測、未見の組合せへの再利用で判断する。

単位長の潜在では、READMEのスコアは次のようになる。

\[
-\|q-y_c\|^2/\tau=-2/\tau+(2/\tau)q^\top y_c.
\]

したがって識別項の形式は、温度を読み替えた通常の内積型対照予測と同じである。この事実はモデル研究の価値を否定しないが、「新しい損失式だから共有世界が形成される」という説明には使えない。負例選択の影響自体にも先行研究があるため、本研究では、その学習圧力が共有世界モデルの機能にどう届くかが問われる。[Biza et al., 2021](https://arxiv.org/abs/2107.11676v1)

**討論4：後続操作ができれば、世界が共有されたと言えるか。** 対象はREADME §14–18。

実験担当：赤の操作が終わってから青を再観測すれば、途中で失った青の位置を取り直せる。赤→青の成功だけでは、内部で赤の未来を予測している間にも青が存在し続けたかは分からない。

理論研究者：そこで、観測から作った状態と、予測によって進めた状態を区別する。初期観測から赤の行動列を自己回帰的に予測し、実測未来を途中で入れずに、その状態から青の操作結果まで予測できるかを調べる。

査読者：表現から青の位置が読めるだけでも不十分である。青を動かす候補行動の結果が変わるか、実際の未来に合うかが必要になる。位置を保存しただけの表現と、操作に使える世界モデルを区別できる。

研究責任者：計画で失敗した場合は、世界モデルが失敗したと断定できるか。

理論研究者：予測が正確でも、潜在Goal距離が行動の良し悪しを適切に順位付けしない場合がある。同じCEMを使っても、表現の距離構造が違えば結果は変わる。世界の認識、遷移の予測、目標に向けた利用を分けて診断する必要がある。

統合判断：後続制御は重要な最終評価である。その前に、同じ内部状態から複数の継続行動を予測できるか、別タスクへ切り替えた予測が成立するかを確認する。長い遮蔽や数分間の記憶を新たに要求する必要はない。READMEで想定する短い予測展開の中で、共有された世界が保たれるかをまず測る。

**モデル側で具体化すべき学習原理。** 次の表は、新しいアルゴリズムが完成したという記述ではなく、マルチタスク世界モデルとして満たすべき要件である。

| 要件 | モデルに求めること | 現行READMEの対応と不足 |
|---|---|---|
| 共有された状態認識 | 経験の出所によらず、同じ予測上の状況を互換な状態として扱う | Eは共有されるが、タスクをまたぐ互換性の検証が弱い |
| 行動に応じた共有遷移 | 一つの状態から、異なる操作による変化を予測する | A・Fと交差予測が対応。物体の実変化を学んだかは別途必要 |
| 世界の持続 | 操作していない要素も、別の操作で必要なら予測状態に残す | 四択が保持圧力になる場合はある。自己回帰中の保持が未実証 |
| 経験の接続 | ある操作の予測終点を、別操作の予測始点として利用する | 共有Fで実行可能だが、学習・評価の中心要件として未具体化 |
| 外観と物理変化の区別 | 撮影条件によらず、操作に必要な状態差を保つ | 異視点予測が対応。可観測性と情報消失の両面を確認する |
| 非崩壊と学習安定性 | 予測しやすい定数や少数の近道へ逃げない | SIGReg置換は候補。十分な情報保持と安定性は保証されない |

ここで「共有された状態」は単一画像の潜在ベクトルだけとは限らない。位置が同じでも速度が違えば、画像一枚は同じで未来は異なる。現行Fは履歴を使えるため、速度を推定できる可能性がある。モデル全体の予測不能を意味する問題ではない。

一方、README §12.3の物理状態の説明と、単画像を教師にする§7の定義は整理が必要である。画像ごとの特徴zと、観測・行動履歴を含む予測状態を区別し、何について十分性や情報保持を主張するのかをそろえる。履歴を予測状態とする整理は、直ちに新しいネットワークの追加を必要としない。

同じロボット・同じ行動座標・同じ制御周期を最初の範囲とするのも合理的である。その条件では、タスクの目標が変わっても物理的な遷移法則は共有できる。摩擦や道具の状態が違って遷移が変わるなら、その違いは観測・履歴から推定すべき世界の要素になる。Goalは、学習した世界の中で何を起こしたいかを計画器に伝える役割として残す。

**現在案から考えられるモデルの整理。** 現行READMEは、対応表に基づく予測・識別を主目的関数にしている。一つの検討案は、すべての有効な経験に共有LeWMの行動条件付き未来予測を適用し、対応が得られる経験には、状態差の保持や撮影条件間の整合を促す項を追加する構成である。

この構成なら、通常のタスク経験からも世界を学び、交差対応はその学習を補強する位置付けになる。ただし、これは現行仕様からの変更案であり、既に実装・検証された方法ではない。また、既存の経験に対応情報がなければ、正しい対応を自動的に用意できるとは限らない。

対応をモデル自身が推定して学ぶ場合にも、「今の埋め込みが近いから同じ状態」と自己確認するだけでは、誤った同一視を固定する可能性がある。時間的な連続性、実行行動、複数の実測未来との整合が、その状態認識を支えているかを確認する必要がある。

SIGRegは、まず世界モデルを安定に学習する手段として評価すべきであり、除去そのものを成功条件にしない。原著LeWMは予測とSIGRegで表現を学習するが、その成功は今回の構成を保証するものではない。[LeWM v3](https://arxiv.org/abs/2603.19312v3)

物体単位の表現、追加の記憶機構、タスクごとの専門モデルは、この段階で必須とは判断できない。例えば非操作対象が予測中に失われるなら、物体単位の構造を比較する理由になる。履歴不足で同じ観測から異なる未来を区別できないなら、記憶を強める理由になる。先に不足を特定し、追加構造がそれを解決するかを問うべきである。

**マルチタスク世界モデルとしての達成判定。** 最も重要な比較相手は、複数タスクの経験をそのまま共有LeWMで学習した基準である。まず、この基準が共有された認識と予測をどこまで獲得するかを調べ、その不足を現案が解決できるかを評価する。

単純な共有学習で必要な機能が得られるなら、それも目的を満たす一つの解であり、追加損失を必須とする理由はない。「マルチタスク世界モデルを作れたか」と「提案した追加学習に独自の改善効果があるか」は、別の判定として扱う。

| 評価 | 実施すること | 世界モデルとして確かめる性質 |
|---|---|---|
| 同じ状態への経験間の整合 | 異なるタスク履歴から到達した、後続予測に必要な状態が同じ状況で、同じ行動を与える | 経験の出所に依存した矛盾がない |
| 一つの状態からの複数予測 | 同じ初期履歴から、赤操作・青操作等の実測結果を予測する | 一つの世界認識を複数の操作に使える |
| 予測状態の接続 | 赤操作の予測終点から、実測未来の再入力なしに青操作を予測する | 別タスクへ移っても世界の状態が引き継がれる |
| 未見の組合せへの再利用 | モデルを固定し、既知の操作を未見配置・順序で評価する | 経験の記憶を超えた状態・変化の再利用 |
| 非操作対象の保持 | 観測潜在と予測潜在で読み出しを分け、その物体への後続行動結果も測る | 予測世界に必要な要素が残り、使われる |
| 見え方を変えた同じ操作 | 未見外観で物理予測と制御を測る | 世界認識が撮影条件だけに依存していない |
| 共通計画器での複数タスク | 同じGoal条件・計画予算で各操作と組合せを評価する | 学習された世界が目的に応じて利用できる |

同じ「状態」とみなすときは、位置だけでなく、速度や接触等の未来を左右する違いをそろえる。履歴から推定できる隠れた違いまで消して一致を要求してはいけない。

モデル間の予測誤差を潜在MSEだけで比較すると、表現のスケールや幾何の差を測る可能性がある。物理状態の読み出しや実測結果との対応を共通指標にする。ただし、読み出しに失敗しただけで情報の完全消失とは断定せず、同じラベル数と容量の線形・小規模非線形読み出し等で、利用可能性として評価する。

計画での成績は、同じ候補行動に対する実測未来の潜在Goal距離と、Fの予測未来の距離を比べて診断できる。前者でも行動を選べなければ表現とコスト、前者は良く後者が悪ければ予測器を疑える。物理状態による採点を診断基準に使う場合は、画像入力の本手法とは分けて報告する。

比較には同じ学習経験、容量、観測・行動形式、調整予算を使い、物理軌道の派生ファミリーを学習と評価で分ける。複数seedとタスク別結果を報告する。単一タスク学習との比較は、共有による利益と干渉を調べる補助になるが、データ量・容量・計算量の差を明記する。

**実現可能性と優先順位。** 共有E・A・F、潜在の自己回帰予測、共通計画器という構成は、小規模なマルチタスク世界モデルを作る出発点として妥当である。最初は同一ロボットの二物体操作など、物理と行動形式が共通する範囲でよい。

最初に確かめるべきなのは、固定した撮影条件で、単純な混合学習LeWMがどこまで状態と変化を共有できるかである。その上で現案の学習を加え、予測状態の接続と未見の操作組合せが改善するかを調べる。撮影条件への頑健性は、その共有世界を保てるかという次の評価軸にする。長期記憶、未知の物理、実機移行を同時に解く必要はない。

優先順位は次の順になる。

1. 観測特徴と履歴を含む予測状態の定義をそろえる。
2. 複数タスク混合の共有LeWMを基準として、何を共有でき、何を失うか確認する。
3. 現案の学習原理が、別タスクへ接続できる状態と遷移を改善するか評価する。
4. 不足がある場合に、整合損失・状態構造・記憶等の変更を一つずつ検討する。
5. モデルを固定した再利用と、共通計画器による操作を確認する。

学習安定性には、SIGReg併用版の定義上の注意もある。正規化後では常に‖z‖²≤1だが、D次元の標準ガウスはE‖z‖²=Dになる。標準ガウスを目標にするSIGRegを、同じ単位長特徴にそのまま課すと目標が両立しない。正規化前へ適用する等、適用先とスケールを明記する必要がある。併用自体が学習不能だという断定ではない。[LeWM v3、Appendix A](https://arxiv.org/html/2603.19312v3)

計算資源と必要学習量は未測定である。大きな追加ネットワークを要求しない点は有利だが、複数時刻の逆伝播や比較条件の数によって研究全体の負担は増える。実装後の短い試行で、一更新の時間・最大メモリ・計画時間を測って判断すべきである。

**関連研究との関係。** 複数タスクの世界モデル自体には先行例がある。TD-MPC2は一つのモデル／エージェントで多数のタスクを扱う構成を示している。ただし、タスク埋め込みや報酬・価値学習を含むため、今回の共有LeWMの学習が成立する直接の証拠にはならない。研究上の比較軸は、軽量な予測構造で、複数タスクに再利用できる世界をどう獲得するかになる。[TD-MPC2、§3.1–3.3](https://arxiv.org/html/2310.16828v2)

複数ステップの潜在予測と画像拡張はSPR、複数視点を使う世界モデル学習はMV-MWMに先行例がある。これらを組み込んだことだけで新規性を確定せず、マルチタスクの状態共有と再利用が実際に改善することを示す必要がある。[SPR](https://arxiv.org/abs/2007.05929v4)、[MV-MWM](https://proceedings.mlr.press/v202/seo23a.html)

SIGRegを識別課題に置き換える方向にはAC-MTMがあり、時間中心化SIGRegはロボット方策学習での表現を扱う。両者は近接した比較対象だが、本研究の目的達成を「SIGRegを外せたか」へ置き換えるべきではない。[AC-MTM v1](https://arxiv.org/abs/2608.17542v1)、[Temporally Centered SIGReg v3](https://arxiv.org/abs/2607.26924v3)

**最終判定。** READMEの方向は、複数タスクの経験から一つの世界を学ぶ目的に沿っている。特に、Goalだけで重要情報を選別せず、後続操作に必要な状態を残す方針と、行動条件付きの共有予測器を維持する方針は適切である。

不足しているのは、「表の中の未来を識別する学習」と「経験をまたいで再利用できる世界の形成」の間を、モデルの要件としてつなぐ部分である。現在の手法でそれが自然に得られる可能性はあるが、学習構造だけから確定はできない。

成功と呼ぶべき結果は、**LeWMが複数タスクの経験から共通の予測状態と変化の規則を獲得し、ある操作で認識・予測した状態を、別の操作にも使えるようになること**である。四択精度、データの効果、非崩壊だけが改善した場合は部分的な結果であり、この目的は未達と判定する。

READMEの研究目的は、次のように明記すると、その焦点が保たれる。

> 本研究は、複数タスクの経験から、操作対象と周辺の状態、および行動に伴う変化を共有の潜在表現と予測器として学習するマルチタスクLeWorldModelを目指す。あるタスクで獲得した状態認識を別タスクの未来予測へ再利用でき、撮影条件が変わっても必要な状態差を保持できる学習原理を検討する。交差継続予測は、その共有世界の形成を促す一つの方法として評価する。
